# ETA Jumpsuit Restorations

Website for ETA Jumpsuit Restorations — restoration and repair of stagewear for Elvis Tribute Artists (jumpsuits, capes, belts, and more).

## Contents

- `index.html` — the complete site: about, services, pricing, and a photo gallery of restoration work. Self-contained (fonts and photos are embedded), so it can be opened directly or hosted as-is.

## Hosting on GitHub Pages

To serve this repo as a live website:

1. Go to the repo's **Settings → Pages**
2. Under **Build and deployment**, set **Source** to `Deploy from a branch`
3. Set **Branch** to `main` and folder to `/ (root)`
4. Save — the site will be live at `https://<username>.github.io/eta-jumpsuit-restorations/` within a few minutes
